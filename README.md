# TouchHub GitHub Pages

Project site: https://ziijialee.github.io/touchhub/

Static HTML, CSS, JS, and media. Deploy from the root of main; no build step. `assets/videos/touchhub-original.mp4` is the owner-selected project film used by the main player. The original narration and optional English captions are preserved. The layout follows the TactAlign project page: title and video first, followed by the abstract, inline historical animations, task-specific six-method comparisons, transfer experiments, and a project-website citation. Font licenses are under assets/type/. Review-only manuscript PDFs and the internal media gallery are deliberately excluded.
