# TouchHub GitHub Pages

Project site: https://ziijialee.github.io/touchhub/

Static HTML, CSS, JS, and media. Deploy from the root of main; no build step. `assets/videos/touchhub-original.mp4` is the owner-selected project film used by the main player. The original narration and optional English captions are preserved. Layout references: [TactAlign](https://yswi.github.io/tactalign/) and the [Nerfies project-page template](https://github.com/nerfies/nerfies.github.io). Page structure: title and video first, followed by the abstract, inline historical animations, task-specific six-method comparisons, transfer experiments, and a project-website citation. Font licenses are under assets/type/. Review-only manuscript PDFs and the internal media gallery are deliberately excluded.

The taxel layout image is from slide 4 of the reference deck. The fingertip example is the animation region from the final slide-6 render, retaining its end hold. Table 2 and Table 4 values are displayed interactively. The clip-selection manifest is retained offline for verification and is not part of the public presentation.
